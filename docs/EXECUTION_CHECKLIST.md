# Checklist antes da entrega

## Funcional

- [ ] `npm install` executado sem erro
- [ ] `npm run test:web` passou
- [ ] `npm run test:api` passou
- [ ] `npm run test:smoke` passou
- [ ] relatório HTML aberto e revisado em `cypress/reports`
- [ ] screenshots/vídeos de falha removidos após correção

## Performance

- [ ] smoke JMeter com 1 usuário passou
- [ ] autorização para gerar carga confirmada
- [ ] teste de carga executado
- [ ] teste de pico executado
- [ ] dashboard HTML gerado
- [ ] `PERFORMANCE_REPORT_TEMPLATE.md` preenchido com números reais

## Repositório

- [ ] `node_modules` não commitado
- [ ] nenhum dado pessoal/credencial no repositório
- [ ] README revisado
- [ ] GitHub Actions verde
- [ ] link do repositório público conferido em janela anônima
